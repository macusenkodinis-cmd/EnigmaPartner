# Enigma Partner

Готовый статический лендинг для GitHub Pages.

## Файлы
- `index.html`
- `style.css`
- `script.js`
- `robots.txt`
- `sitemap.xml`

Папки `images` и `videos` оставьте из текущего проекта без изменений.

Форма заявки пока демонстрационная: она показывает уведомление, но не отправляет данные на сервер.
